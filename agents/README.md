# Профили агентов

Здесь хранятся переиспользуемые роли: ответственность агента, границы решений, ожидаемый результат и навыки, которые помогают его получить. Готовых профилей пока нет; первым добавлен самостоятельный скилл, доступный разным ролям.

Новый переносимый профиль размещайте в `<role-name>/AGENT.md`. Это **соглашение этого репозитория**, а не обещание автоматического распознавания клиентом. `AGENT.md` можно передать агенту как инструкции; адаптер для конкретной среды добавляется только при необходимости.

Все новые профили пишите на английском и по умолчанию используйте скиллы из `skills/en/`. В профиле указывайте отвечать на языке пользователя. Существующие русские версии скиллов хранятся отдельно в `skills/ru/`; одновременно подключайте только одну языковую версию каждого скилла.

В профиле опишите:

- Назначение роли и ситуации, когда она нужна.
- Необходимый контекст, ответственность и границы самостоятельных действий.
- Подходящие скиллы с относительными ссылками и условиями применения.
- Формат результата и условия передачи работы пользователю или другому агенту.

Не копируйте методику скилла в роль. Например, продуктовый менеджер и аналитик рынка могут использовать один `product-market-research`, имея разные полномочия и контекст. Наличие профиля не разрешает автоматически создавать субагентов или делегировать работу.
